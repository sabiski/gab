Gab'Pharma est la plateforme nationale du médicament au Gabon : patients, pharmacies, livreurs, assureurs et autorités sanitaires. Ce guide décrit tout ce que vous pilotez depuis ce tableau de bord, dans l'ordre logique de mise en service.

{# ── 1. Vue d'ensemble ── #}

hub 1. Vue d'ensemble

  • Site public — catalogue, recherche, panier, checkout, suivi commande.
  • Espace patient — /espace/client/ (commandes, ordonnances, messages, fidélité).
  • Espace pharmacie — /espace/pharmacie/ (commandes, stocks, personnel, abonnement).
  • Espace livreur — /espace/livreur/ (courses, QR, incidents).
  • Espace assurance — /espace/assurance/ (contrats, demandes, paiements).
  • Espace autorité — /espace/autorite/ (pharmacies, stocks, campagnes, conformité).
  • Connexion unique — /auth/connexion/ (e-mail ou identifiant + 2FA si activée).

{# ── 3. Pharmacies ── #}

local_pharmacy 3. Mettre une pharmacie en service

  1. Compte titulaire — Utilisateurs → Ajouter, rôle Pharmacien, e-mail obligatoire (identifiants envoyés).
  2. Fiche officine — Pharmacies → Ajouter (ou Modifier) : choisir le Titulaire, statut Active. Colonne « Non rattachée » = le pharmacien se connecte mais ne voit rien.
  3. Abonnement plateforme — Abonnements → Pharmacies (Essentiel / Professionnel / Entreprise).
  4. Connexion pharmacie — /auth/connexion/ → redirection /espace/pharmacie/. Le titulaire gère ensuite stocks, commandes, personnel, messages.
{# ── 4. Catalogue ── #}

medication 4. Médicaments & catalogue

  • Référentiel national : Médicaments (DCI, dosage, forme, ordonnance obligatoire, image).
  • Chaque pharmacie gère ses stocks (prix, quantités, alertes, péremption) dans son espace.
  • Le patient compare les disponibilités sur le site public puis commande chez une officine.
{# ── 5. Parcours patient ── #}

person 5. Parcours patient (commande)

  1. Inscription / connexion patient → recherche médicament ou pharmacie.
  2. Ajout au panier → checkout (livraison domicile / express / retrait).
  3. Ordonnance : upload si médicament soumis à prescription.
  4. Paiement : Moov Money, Airtel Money, carte, COD, ou en pharmacie (+ assurance éventuelle).
  5. Confirmation → code de retrait / QR livraison → suivi temps réel.
  6. Suivi admin : Commandes.
{# ── 6. Pharmacie opérationnelle ── #}

storefront 6. Côté pharmacie (après connexion)

  • Commandes — accepter, préparer, valider / refuser ordonnance, marquer prête.
  • Stocks — inventaire, seuils bas, dates de péremption.
  • Personnel — caissier, préparateur, pharmacien adjoint (droits ERP).
  • Messages / notifications — chat patient, urgences SOS.
  • Remise livreur — QR / code de traçabilité.
{# ── 7. Livraison ── #}

local_shipping 7. Livreurs & livraison

  1. Créer le compte via Livreurs (profil véhicule, documents).
  2. Le livreur se connecte → voit les courses assignées / à prendre.
  3. Scan QR patient ou code → livraison validée.
  4. Incidents (casse, retard, client absent) : Incidents / Support — réaffectation possible.
{# ── 8. Paiements ── #}

payments 8. Paiements

  • Suivi global : Paiements.
  • Mobile Money / carte via E-Billing (Digitech) — une commande n'est « payée » qu'après callback définitif (pas sur un simple PENDING).
  • COD : acompte + solde à la livraison ; paiement en pharmacie au retrait.
  • Part assurance : enregistrée séparément, validée par l'assureur.
{# ── 9. Assurances ── #}

health_and_safety 9. Compagnies d'assurance

  1. La compagnie s'inscrit sur le formulaire public (pas de création manuelle admin).
  2. Vous examinez le dossier (RCCM, NIF, enquête) dans Assurances — pilotage → Valider ou Refuser.
  3. Activer l'abonnement : Abonnements → Assurances (accès portail bloqué tant que non payé / activé).
  4. Ensuite l'assureur gère assurés, contrats, demandes de prise en charge, fraudes, stats.
{# ── 10. Autorités ── #}

account_balance 10. Autorités sanitaires

  • Comptes : Autorités sanitaires (validation des inscriptions en attente).
  • Portail : pharmacies connectées, ruptures de stock, conformité, campagnes de santé, rapports.
  • Vous pouvez aussi consulter ces vues depuis le menu « Espace Autorités » de cette sidebar.
{# ── 11. Abonnements ── #}

card_membership 11. Abonnements plateforme

  • Pharmacies — forfaits Essentiel / Professionnel / Entreprise (mensuel ou annuel −20 %).
  • Assureurs — Standard / Professionnel / Entreprise ; enregistrement du paiement puis activation.
  • Page : Abonnements.

support_agent 12. Support, tickets & notifications

  • Réclamations — tickets patients / partenaires.
  • Incidents livraison — suivi et réaffectation.
  • Notifications — campagnes / messages plateforme.
{# ── 13. Site public ── #}

web 13. Contenu du site public

  • Hero accueil — titres, CTA, image.
  • Publicités — bannières.
  • Conseils — articles santé / conseils pharmacien.
{# ── 14. Paramètres & sécurité ── #}

settings 14. Paramètres & sécurité

  • Paramètres — plafonds paiement, 2FA, options plateforme.
  • Rôles & permissions — modules admin + droits ERP pharmacie.
  • Journal d'audit — actions sensibles (créations, suspensions…).
{# ── 15. Checklist démarrage ── #}

checklist 15. Checklist de démarrage (ordre recommandé)

  1. Paramètres plateforme + SMTP (envoi des identifiants).
  2. Médicaments du référentiel (ou import).
  3. 1re pharmacie : compte pharmacien → fiche → titulaire → Active → abonnement.
  4. 1er livreur (profil + documents).
  5. Hero / conseils / pub pour le site public.
  6. Tester un parcours patient complet (commande + paiement simulé ou E-Billing LAB).
  7. Valider une inscription assureur de test + abonnement.
  8. Valider un compte autorité de test.
{# ── 16. Dépannage ── #}

warning Dépannage fréquent

  • Pharmacien connecté mais dashboard vide — pas de titulaire sur la fiche Pharmacies.
  • Assureur ne peut pas entrer — inscription non validée ou abonnement non activé.
  • Images qui disparaissent — volume Dokploy /app/media + stockage MySQL (re-téléverser une fois après déploiement).
  • CSRF à la connexion — recharger la page en HTTPS ; vérifier DJANGO_CSRF_TRUSTED_ORIGINS.
  • Paiement « réussi » trop tôt — ne jamais confirmer sur PENDING ; attendre le callback E-Billing.
  • 2FA à chaque fois — cocher « Se souvenir de cet appareil » (30 jours).
