La fiche pharmacie (officine) et le compte utilisateur (titulaire ou personnel) sont distincts. Sans titulaire rattaché, le pharmacien peut se connecter mais n'accède à aucun portail.

  1. Créer le compte titulaire

    Utilisateurs → Ajouter — rôle Pharmacien, e-mail obligatoire (identifiants envoyés par mail). Optionnel : sélectionner la pharmacie dans « Pharmacie titulaire ».

  2. Créer ou compléter la fiche officine

    Pharmacies → Ajouter ou Modifier une officine existante — choisir le Titulaire dans la liste. Colonne « Titulaire » : Non rattachée = aucun accès portail.

  3. Activer l'officine sur le site

    Statut de la pharmacie : Active (visible catalogue / commandes). En attente tant que le dossier n'est pas validé.

  4. Activer l'abonnement plateforme

    Abonnements plateforme — onglet Pharmacies — choisir l'officine, le forfait, puis Activer. Le titulaire reçoit une notification dans son espace.

  5. Connexion côté pharmacie

    URL : {% url 'login' %} (identifiant = e-mail ou nom d'utilisateur + mot de passe reçu). Après connexion → /espace/pharmacie/ (tableau de bord). Si la 2FA est active : cocher « Se souvenir de cet appareil » pour éviter le code à chaque visite.

{% if not compact %}

warning Dépannage fréquent

  • Portail vide après connexion — vérifier le titulaire sur la fiche pharmacie.
  • Erreur CSRF à la connexion — recharger la page (F5) et réessayer en HTTPS.
  • Personnel supplémentaire — le titulaire peut ajouter des employés depuis Personnel dans son espace, ou via un compte Pharmacien rattaché en employé.
